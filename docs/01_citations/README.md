## 📝 Citation Guidelines

### BibTeX Format
```bibtex
@article{authorYear,
  title={Paper Title},
  author={Author Names},
  journal={arXiv preprint arXiv:XXXX.XXXXX},
  year={YYYY}
}
```

### In-text Citation
- APA Style: (Author, Year)
- IEEE Style: [1]

---

## 🔍 How to Add New Papers

1. **Download Paper**: arXiv, ACL, NeurIPS 등에서 다운로드
2. **Summarize**: 핵심 내용 요약 (1-2페이지)
3. **Categorize**: 적절한 서브폴더 선택
4. **BibTeX**: 참고문헌 정보 추가
5. **Update**: 이 README 업데이트
